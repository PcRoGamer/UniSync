### MCP Server Installation Guide
If the `unisync` Model Context Protocol (MCP) server tools are not already configured in your environment, add this server definition to your MCP client configuration (e.g. Claude Desktop `%APPDATA%\Claude\claude_desktop_config.json`, Cursor, or Antigravity):

```json
{
  "mcpServers": {
    "unisync": {
      "command": "python",
      "args": ["-m", "unisync.mcp"],
      "cwd": "C:\\Users\\Admin\\Desktop\\UniSync",
      "env": {
        "PYTHONPATH": "backend"
      }
    }
  }
}
```
